# Do Not Break Rules

This file is intentionally strict.

## Absolute baseline

The final accepted baseline is **TuniAtlas v16**.

Do not redesign it.

## Do not change

- Colors.
- Typography.
- Dark/light switch style.
- EN/FR switch style.
- Header structure.
- Account dropdown content.
- Job card design direction.
- Profile stepper direction.
- Settings direction.
- About page content direction.
- Compact wording style.

## Do not add

- More menu.
- Dashboard page.
- Admin UI.
- Separate Stage page.
- Separate Alternance page.
- Already applied state.
- Expired job state.
- Urgent job state.
- Postulate button on job cards.
- Long marketing text.
- Long helper explanations.

## Do not reintroduce removed wording

Do not reintroduce:

- OAuth account.
- Optional.
- Check extracted data.
- Upload or replace file.
- or email
- Data controls in settings.
- Account and job use rules.
- Missions/Profile job detail blocks that were removed earlier.

## Profile mobile rule

If sticky bottom action bar exists on mobile, remove/hide duplicate inline action buttons on mobile.

## Settings mobile rule

Collapsed settings cards need visible gap between them. They must not touch.

## Index mobile rule

Jobs should be reachable quickly. Search/stats/filter sections should not force long scrolling before job results.

## Implementation rule

If a developer/agent wants to change visible UI, they must explain why it is necessary and ask first.
