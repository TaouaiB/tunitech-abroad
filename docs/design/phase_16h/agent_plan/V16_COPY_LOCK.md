# TuniAtlas V16 Copy Lock

## Principle

No extra wording.

The UI should be compact and action-focused. Do not explain obvious fields or states.

## Banned extra helper text

Do not add or reintroduce lines such as:

```text
OAuth account.
Optional.
Check extracted data.
Upload or replace file.
or email
```

Also avoid similar helper lines unless they are required for validation or user action.

## Allowed copy

Allowed text:

- labels
- buttons
- validation errors
- toast messages
- loading status words
- state titles from v16
- compact section names

## Not allowed

Avoid:

- marketing paragraphs not in v16
- explanatory subtitles under every heading
- “This helps us...” explanations
- repeated “optional” labels
- obvious helper text under form fields
- agent-invented onboarding text

## Language behavior

Preserve v16 EN/FR behavior.

Do not add new translations unless a v16 label requires it.

## Copy acceptance rule

If a phrase is not in v16 and is not necessary for validation, do not add it.
