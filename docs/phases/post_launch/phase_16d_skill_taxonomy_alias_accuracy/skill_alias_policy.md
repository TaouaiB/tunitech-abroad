# Skill Alias Policy

Canonical taxonomy is the stable label space for deterministic matching and future ML.

Required alias behavior examples:

```text
.net -> .NET
dotnet -> .NET
dot net -> .NET
.net core -> .NET or ASP.NET Core according to chosen taxonomy
asp.net core -> ASP.NET Core
node js -> Node.js
reactjs -> React
postgres -> PostgreSQL
c sharp -> C#
csharp -> C#
ci/cd -> CI/CD
```

Unknown skills go to review. Do not auto-create canonical Skill rows from unknown extraction.
